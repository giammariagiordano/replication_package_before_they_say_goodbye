Replication package

Before They Say Goodbye: Psychological Signals of Developer Disengagement in Open Source

Code and pseudonymized data to reproduce the results of the paper: the mining pipeline, the measures per developer and month, and the analysis-ready tables of the three research questions. Reproducing the tables takes a few minutes on a laptop and needs no GitHub access.

Reproduce the results

Every number of the paper can be recomputed from data/, with the same functions used for the paper and without access to GitHub. You need Python 3.10–3.12.

cd code/backend
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

1. Research questions and sensitivity analyses

python scripts/reproduce.py ../../data          # everything, about ten minutes
python scripts/reproduce.py ../../data --main   # RQ1–RQ3 only, about two minutes

The script fits the mixed models of RQ1, the base, full, and extended Cox models of RQ2, the cause-specific models of RQ3 and the models by destination, the core/peripheral analysis, and, on data/sensitivity/, the analyses under alternative thresholds and with explicit anger only. It writes every estimate to data/results.json and prints one line per set of tables with the estimates of the sensitivity table.

2. Dataset statistics

python scripts/descriptives.py ../../data

Bots by detection rule, developers and developer-months, the selection of sustained developers, the table of the dataset, the coverage of the lexical, recognition, citizenship, and accommodation measures, explicit anger, messages not in English, and the outcomes after the exit, written to data/descriptives.json.

3. Emotion classifiers

data/classifier/ holds the probabilities that each RoBERTa model assigns to the 400 comments of the GitHub test set (Imran et al.) and to the 7,122 comments of the polarity gold standard (Novielli et al.), identified by the datasets' ids. The gold standards cannot be redistributed; once downloaded, the table of the classifiers is recomputed without a GPU:

python scripts/emotions/score_predictions.py ../../data/classifier gh_clean.csv github_gold.csv

The docstring of the script explains how to obtain the two files. The fine-tuned final model (≈ 480 MB) is available at MODEL_URL; with it, scripts/emotions/evaluate_classifiers.py regenerates the predictions, and the pipeline labels new messages exactly as in the paper.

The results.json and descriptives.json shipped in the package are the outputs of these commands on the shipped data, so the numbers can be compared with the paper without running anything.

Data

The tables follow the settings of the paper: abandonment after 12 months without activity while the project is still observed, covariates summarizing the previous three months, and developers who enter the risk set after their sixth active month. Bots are excluded everywhere except in developers and messages, where they are flagged. Column names and row counts are listed in data/metadata.json; the measures are defined in the Research Method section of the paper.

Identifiers

project is the public repository name (owner/name). developer and the subject id sid (owner/name:pseudonym) identify a developer within a project through a salted pseudonym, such as amber-heron-3f9a, and person the same person across projects, which clusters the standard errors. The salt is not released. Messages carry no text, but their public GitHub ids, from which the text can be retrieved:

Run the full pipeline

The pipeline clones each repository, mines its GitHub history, merges the aliases of each developer, removes bots, classifies the messages, and computes the measures per developer and month. It runs with Docker and needs one or more GitHub tokens.

cd code
GITHUB_TOKENS=<token> docker compose up --build    # interface at http://localhost:8080

Add the repositories of data/projects.csv.gz from the interface or the API, as described in code/README.md, and place the fine-tuned model and Senti4SD in external/ as the README explains; the worker mines the projects and resumes after interruptions. Once they are done, the paper's results are recomputed from the database with backend/scripts/paper_results.py, and the tables of this package are exported with backend/scripts/replication_export.py.

Mining 2,842 projects takes several days and depends on GitHub's rate limits. Since repositories keep changing, a new mining run will not return exactly the same data; the shipped tables are the snapshot analyzed in the paper (October 2026).

Emotion classifier

The scripts in backend/scripts/emotions/ prepare the public gold standards (Stack Overflow, Novielli et al.; GitHub, Imran et al.), retrain EmoTxt, fine-tune RoBERTa with a validation split, with 5-fold cross-validation, and as a final model, and evaluate them as in the paper. Retraining needs a GPU and may differ slightly from the released model because of nondeterminism; docs/EMOTIONS.md reports both trainings we ran.

Ethics

The study relies on public data and reports only aggregate results. The psychological signals are proxies inferred from language and reactions, not diagnoses, and must not be used to monitor or evaluate individual developers. Pseudonymized data are still personal data: do not attempt to re-identify the developers.
